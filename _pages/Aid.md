## 技术执行与自动化处理规范 (PowerShell 5.1 & Python 跨平台标准)

0. 处理脚本放在 /HandleScript/ 文件夹下

1. **高效准确移动的核心策略**：
   - **先检查后移动**：在移动前必须校验目标路径是否存在同名文件。若存在，应通过重命名（如增加时间戳或随机后缀）避免覆盖，严禁静默覆盖。
   - **异常捕获机制**：自动化脚本必须包含 `try-except` 或 `ErrorAction` 处理。对于权限受限、文件占用（如 PDF 已打开）等错误要实时跳过并记录，而非导致整体任务崩溃。
   - **路径长度预警**：Windows 默认路径上限为 260 字符。对于层级较深的分类（如 `共和国前三十年/.../各省动态资料`），需监控总路径长度，必要时缩短中间文件夹名或文件名。

2. **路径特殊字符处理**：
   - **PowerShell**：遇到文件名包含 `[]` 时，必须强制使用 `-LiteralPath` 参数，否则路径解析会失败。
   - **Python**：使用 `os.path.join` 处理路径，确保在 Windows 环境下的反斜杠兼容性。使用 `shutil.move` 前先校验源文件状态。

3. **编码与识别准则**：
   - **识别第一要义**：脚本匹配中文关键词时，环境必须统一。Python 脚本首行需声明 `# -*- coding: utf-8 -*-`，PowerShell 脚本需保存为 `UTF-8 with BOM`。
   - **正则严谨性**：正则表达需考虑中英文混杂、繁简转化（如 `無政府|无政府`）以及谐音代称。

4. **原子化操作标准**：
   - **分批执行**：单次移动建议不超过 100 个文件，执行后必须立即调用 `ls` 或 `os.listdir` 确认源目录减少数量与目标目录增加数量一致，确保“账实相符”。
