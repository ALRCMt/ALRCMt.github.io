### 1.刷入ImmortalWRT
请注意nand版与emmc版的固件不同，rax3000M与me之类也是不同的  
有官方固件也有各大佬自编译的，请注意恩山237大佬的固件格式.bin与官方新版.itb不一致，Uboot也必须一一对应（不然喜提黑砖，当然可以ttl救砖） 
恩山237大佬的固件：[7981高功率闭源驱动插件openwrt](https://www.right.com.cn/FORUM/thread-8263340-1-1.html)

如果不想折腾，推荐刷ImmortalWRT官方固件   
刷入及部分配置教程：[ImmortalWrt从0到能正常用教程](https://www.right.com.cn/FORUM/thread-8436472-1-1.html)   
我刷的固件：[RAX3000M-237大佬仓库编译自用闭源固件24.10内核版本](https://www.right.com.cn/forum/thread-8433653-1-1.html)   
同上固件的GitHub库：[https://github.com/jiehuihui/immortalwrt24.10-6.6-cmcc_rax3000m-237](https://github.com/jiehuihui/immortalwrt24.10-6.6-cmcc_rax3000m-237)

``` shell

# 保存并退出
#运行以下命令以应用更改
/etc/init.d/network restart 

```

### 3.SLAAC自动分配IPV6
因为我要给PVE分配IPV6，但是由于SM运营商，路由的IPV6地址并不是固定的，好像不能设置静态IPV6
所以选择SLAAC无状态自动配置 

找到设置页面：进入 网络 → 接口
编辑你内网对应的接口（通常是 LAN）

在LAN口设置页面中，切换到 DHCP服务器 选项卡
然后找到 IPv6 RA设置 子页面

请确保以下三个选项按此设置：

RA服务：服务器模式  
DHCPv6服务：服务器模式  
NDP代理：已禁用  

最后应用并保存

### 5.安装Lucky配置网络

huihui888大佬编译的版本自带Lucky，没有的去下载软件包，请注意带`luci-app`字样的包指界面支持

打开Lucky后，配置管理密码、安全入口  
如果版本过低，建议更新，官网下载适合你架构的版本上传：[https://github.com/gdy666/lucky](https://github.com/gdy666/lucky)

**I.配置IPV6动态域名**

动态域名 → 添加任务  
我选择Cloudflare，按照指示创建令牌填入  
选择开启{ipv6Addr}，获取公网IP方式随便  
如果你是绑定路由器LAN口IPV6，可以选择**通过网卡获取**  

如果绑定其下设备IPV6，请选择**通过脚本获取**  
脚本如下  
``` shell
#!/bin/bash
# 获取路由器LAN口（br-lan）的当前公网IPv6前缀（前4段）
lan_prefix=$(ip -6 addr show br-lan | grep inet6 | grep -v '^fe80' | awk '{print $2}' | cut -d ':' -f 1-4 | head -n 1)
# 定义基于其MAC地址计算出的固定后缀，替换"xxxx:xxxx:xxxx:xxxx"（EUI-64格式）
interface_id="xxxx:xxxx:xxxx:xxxx" 
# 拼接成完整的IPv6地址
host_ipv6="${lan_prefix}:${interface_id}"
echo "$host_ipv6"

```
由MAC地址得到EUI-64格式后缀的计算器：[EUI-64 Calculator](https://eui64-calc.princelle.org/)  
然后再尝试在公网访问域名

### 6.自动定时开关机

编辑Lucky内**计划任务**

开机可以网络唤醒，而关机需要自定义脚本  
不知道为什么，我这里ImmortalWRT没办法配置SSH密钥，所以安装`shpass`包来代替，缺点就是脚本里密码是明文，所以要注意  
 
`nano /mnt/pve_shutdown_pass.sh`创建脚本，编辑内容如下，替换 {YOURIP} {KEY}  

``` shell
#!/bin/ash
PVE_HOST="{YOURIP}"
PVE_PASSWORD="{KEY}"

sshpass -p "$PVE_PASSWORD" ssh -o StrictHostKeyChecking=no root@"$PVE_HOST" "shutdown -h +10 '系统将在10分钟后关机进行日常维护，请保存您的工作，如需取消：shutdown -c'"

```

最后在自定义脚本里填`/mnt/pve_shutdown_pass.sh`

### 7.PVE电源控制面板

利用ImmortalWrt自带的 uhttpd 来托管网页和执行脚本

``` shell
# 1. 创建网页根目录
mkdir -p /mnt/pve_web
# 2. 创建CGI脚本目录（将用于存放可执行脚本链接）
mkdir -p /mnt/pve_web/cgi-bin

# 检查uhttpd是否在运行（通常80端口已被LuCI占用）
netstat -tulpn | grep uhttpd
# 如果有多个，先停止所有
killall uhttpd
# 启动新的
uhttpd -p 18080 -h /mnt/pve_web -c /mnt/pve_web/cgi-bin &

# 验证
netstat -tlnp | grep 18080
```
然后创建HDMI文件与CGI脚本,我的目录结构如下

``` shell
 /mnt/pve/  
 ├── index.html  
 ├── favicon.ico  
 └── cgi-bin/  
     ├── ping_server.sh  
     ├── pve_shutdown.sh  
     └── pve_wake.sh  
```

具体脚本内容懒得放了，可以直接照抄我的  
WEB文件：[https://github.com/ALRCMt/MtAIO-Build/tree/main/pve_web](https://github.com/ALRCMt/MtAIO-Build/tree/main/pve_web)  


#### 文件内容解释：  

**_index.html_** 主页，其实里面MAC与IP替换不替换无所谓  

**_pve_wake.sh_** 是唤醒脚本  
使用etherwake工具，没有的先`opkg update && opkg install etherwake`，然后替换MAC  

**_pve_shutdown.sh_** 是关机脚本  
先替换IP，因为使用了PVE的api，所以请先到PVE中生成api  
数据中心 > API令牌 ，然后添加，填写令牌ID，不勾选 “特权分离” 
最后记住密钥与令牌ID，替换脚本中的{PVE_TOKEN_ID}与{PVE_TOKEN_SECRET}

**_ping_server.sh_** 是监测服务器是否在线（可连接）   
只需要替换IP  

然后赋予CGI脚本可操作权
``` shell
chmod 755 /mnt/pve_web/cgi-bin/*
```

最后实现uhttpd自启动，编辑 /etc/rc.local 文件  
``` shell
# 在 exit 0 这一行之前，添加你的启动命令：
# 启动用于PVE控制面板的uhttpd实例
uhttpd -p 18080 -h /mnt/pve_web -c /mnt/pve_web/cgi-bin &
```
保存并退出编辑器。确保 rc.local 文件有执行权限：  
``` shell
chmod +x /etc/rc.local
```
