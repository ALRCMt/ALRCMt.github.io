### 1.刷入ImmortalWRT
请注意nand版与emmc版的固件不同，rax3000M与me之类也是不同的  
有官方固件也有各大佬自编译的，请注意恩山237大佬的固件格式.bin与官方新版.itb不一致，Uboot也必须一一对应（不然喜提黑砖，当然可以ttl救砖）

如果不想折腾，推荐刷ImmortalWRT官方固件   
刷入及部分配置教程：[ImmortalWrt从0到能正常用教程](https://www.right.com.cn/FORUM/thread-8436472-1-1.html)   
我刷的固件：[RAX3000M-237大佬仓库编译自用闭源固件24.10内核版本](https://www.right.com.cn/forum/thread-8433653-1-1.html)   
同上固件的GitHub库：[https://github.com/jiehuihui/immortalwrt24.10-6.6-cmcc_rax3000m-237](https://github.com/jiehuihui/immortalwrt24.10-6.6-cmcc_rax3000m-237)

### 3.SLAAC自动分配IPV6
因为我要给PVE分配IPV6，但是由于SM运营商，路由的IPV6地址并不是固定的，好像不能设置静态IPV6
所以选择SLAAC无状态自动配置 

找到设置页面：进入 网络 → 接口
编辑你内网对应的接口（通常是 LAN）

在LAN口设置页面中，切换到 DHCP服务器 选项卡
然后找到 IPv6 RA设置 子页面

请确保以下三个选项按此设置：

RA服务：服务器模式  
DHCPv6服务：服务器模式  
NDP代理：已禁用  

最后应用并保存

### 5.安装Lucky配置网络

huihui888大佬编译的版本自带Lucky，没有的去下载软件包，请注意带`luci-app`字样的包指界面支持

打开Lucky后，配置管理密码、安全入口  
如果版本过低，建议更新，官网下载适合你架构的版本上传：[https://github.com/gdy666/lucky](https://github.com/gdy666/lucky)

#### I.配置IPV6动态域名

动态域名 → 添加任务  
假设选择Cloudflare，按照指示去[Cloudflare](https://dash.cloudflare.com/)创建令牌填入，选择开启{ipv6Addr}，获取公网IP方式随便  
如果你是绑定路由器LAN口IPV6，可以选择**通过网卡获取**  

如果绑定其下设备IPV6，请选择**通过脚本获取**  
脚本如下  由MAC地址得到EUI-64格式后缀的计算器：[EUI-64 Calculator](https://eui64-calc.princelle.org/)  
``` shell
#!/bin/bash
# 获取路由器LAN口（br-lan）的当前公网IPv6前缀（前4段）
lan_prefix=$(ip -6 addr show br-lan | grep inet6 | grep -v '^fe80' | awk '{print $2}' | cut -d ':' -f 1-4 | head -n 1)
# 定义基于其MAC地址计算出的固定后缀，替换"xxxx:xxxx:xxxx:xxxx"（EUI-64格式）
interface_id="xxxx:xxxx:xxxx:xxxx" 
# 拼接成完整的IPv6地址
host_ipv6="${lan_prefix}:${interface_id}"
echo "$host_ipv6"

```
记录名填你自己的域名（DNS服务商要对上），后公网访问测试一下（记得开防火墙）

#### II.配置Web服务规则

目前只是做到了将IPV6指定到域名，如果许多服务需要访问，可以通过加端口号访问，也可以使用反向代理到指定的子域名，比如  

``` text
a.example.com:443 => 192.168.1.2:8081   
b.example.com:443 => 192.168.1.3:8082
```
因此，在DDNS解析中，可以选择将`*.example.com`域都解析为软路由IPV6，再分配不同子级域名给不同服务, 而且这样还可以使用LTS保障安全

#### III.添加SSL/LTS证书

在Lucky里添加LTS证书，添加方式选**ACME**，机构选**Let's Encrypt**，验证方式填你的域名托管平台，然后为你需要的域名添加证书  
证书会自动续签, 最后在Web服务规则里勾选**LTS**就可以了

### 6.PVE电源控制面板

利用ImmortalWrt自带的 uhttpd 来托管网页和执行脚本

``` shell
# 1. 创建网页根目录
mkdir -p /mnt/pve_web
# 2. 创建CGI脚本目录（将用于存放可执行脚本链接）
mkdir -p /mnt/pve_web/cgi-bin

# 检查uhttpd是否在运行（通常80端口已被LuCI占用）
netstat -tulpn | grep uhttpd
# 如果有多个，先停止所有
killall uhttpd
# 启动新的
uhttpd -p 18080 -h /mnt/pve_web -c /mnt/pve_web/cgi-bin &

# 验证
netstat -tlnp | grep 18080
```
然后创建HDMI文件与CGI脚本,我的目录结构如下

``` shell
 /mnt/pve/  
 ├── index.html  
 ├── favicon.ico  
 └── cgi-bin/  
     ├── ping_server.sh  
     ├── pve_shutdown.sh  
     └── pve_wake.sh  
```

具体脚本内容懒得放了，可以直接照抄我的  
WEB文件：[https://github.com/ALRCMt/MtAIO-Build/tree/main/pve_web](https://github.com/ALRCMt/MtAIO-Build/tree/main/pve_web)  


#### 文件内容解释：  

**_index.html_** 主页，其实里面MAC与IP替换不替换无所谓  

**_pve_wake.sh_** 是唤醒脚本  
使用etherwake工具，没有的先`opkg update && opkg install etherwake`，然后替换MAC  

**_pve_shutdown.sh_** 是关机脚本  
先替换IP，因为使用了PVE的api，所以请先到PVE中生成api  
数据中心 > API令牌 ，然后添加，填写令牌ID，不勾选 “特权分离” 
最后记住密钥与令牌ID，替换脚本中的{PVE_TOKEN_ID}与{PVE_TOKEN_SECRET}

**_ping_server.sh_** 是监测服务器是否在线（可连接）   
只需要替换IP  

然后赋予CGI脚本可操作权
``` shell
chmod 755 /mnt/pve_web/cgi-bin/*
```

最后实现uhttpd自启动，编辑 /etc/rc.local 文件  
``` shell
# 在 exit 0 这一行之前，添加你的启动命令：
# 启动用于PVE控制面板的uhttpd实例
uhttpd -p 18080 -h /mnt/pve_web -c /mnt/pve_web/cgi-bin &
```
保存并退出编辑器。确保 rc.local 文件有执行权限：  
``` shell
chmod +x /etc/rc.local
```

### 7.挂载外部储存介质

我在这里将一个多余的U盘挂载在ImmortalWRT做备份目录  
首先建议U盘系统刷exFAT，其格式支持得最好

然后插入U盘，查看WEB的 **系统** > **挂载点** ，点击底部的 添加 按钮。

勾选“启用”以启用该挂载点  

UUID：在下拉菜单中选择你的U盘。建议使用UUID来识别设备，因为它是唯一的，即使U盘盘符发生变化也不会影响挂载  
挂载点：在“自定义”输入框中，输入挂载路径 如/mnt/sda1  
文件系统：在下拉菜单中选择你的U盘格式，如果不确定，可以留空让系统自动识别  

其他选项保持默认即可，然后点击 **保存**

应用配置：回到“挂载点”页面，点击右下角的 **保存并应用** 按钮，系统会自动尝试挂载  
如果成功，你将在“已挂载的文件系统”列表中看到 /dev/sda1 挂载在 /mnt/sda1

### 8.自动备份配置文件

当由于一些原因不得不重刷ImmortalWrt时，我们希望可以快速恢复配置  
所以编辑了这么一个备份脚本，自动备份WRT配置、已安装包名单及Lucky配置  

我将一个U盘插在RAX3000M的USB口上，并挂载在/mnt/sda1，将备份文件储存在其中  
TIPS：Lucky的备份格式是zip，请先安装软件包`7z`以获取zip支持

```shell
# 编辑脚本，目录随便
nano /mnt/sda1/auto-backup.sh
```
```shell
#!/bin/sh

# 简单备份脚本
BACKUP_DIR="/mnt/sda1/TarBack"
PKG_DIR="/mnt/sda1/PackageBack"
LUCKY_DIR="/mnt/sda1/LuckyBack"
# 备份文件数量上限，去旧留新
MAX_BACKUP_FILES=10
MAX_PKG_FILES=5
MAX_LUCKY_FILES=10

# 创建备份目录
mkdir -p "$BACKUP_DIR" 2>/dev/null
mkdir -p "$PKG_DIR" 2>/dev/null
mkdir -p "$LUCKY_DIR" 2>/dev/null

# 1. 生成系统备份文件
sysupgrade -b "/tmp/backup-$$.tar.gz" 2>/dev/null

# 移动到备份目录并重命名
if [ -f "/tmp/backup-$$.tar.gz" ]; then
    BACKUP_NAME="backup-ImmortalWrt-$(date +%Y%m%d-%H%M%S).tar.gz"
    mv "/tmp/backup-$$.tar.gz" "$BACKUP_DIR/$BACKUP_NAME" 2>/dev/null
    
    # 限制备份文件数量
    ls -tp "$BACKUP_DIR"/backup-*.tar.gz 2>/dev/null | tail -n +$(($MAX_BACKUP_FILES + 1)) | xargs -r rm -f
fi

# 2. 备份已安装软件包列表到另一个文件夹
PKG_FILE="installed-packages-$(date +%Y%m%d-%H%M%S).txt"
opkg list-installed > "$PKG_DIR/$PKG_FILE" 2>/dev/null

# 限制软件包列表文件数量
ls -tp "$PKG_DIR"/installed-packages-*.txt 2>/dev/null | tail -n +$(($MAX_PKG_FILES + 1)) | xargs -r rm -f

# 3. 备份lucky配置（.lkcf文件）
if [ -d "/etc/config/lucky.daji" ]; then
    LUCKY_FILE="lucky-backup-$(date +%Y%m%d-%H%M%S).7z"
    
    # 查找.lkcf文件
    LKCF_FILES=$(find "/etc/config/lucky.daji" -name "*.lkcf" -type f 2>/dev/null)
    
    # 如果有.lkcf文件，则用7z打包
    if [ -n "$LKCF_FILES" ]; then
        # 使用7z创建压缩包
        7z a -t7z "$LUCKY_DIR/$LUCKY_FILE" $LKCF_FILES >/dev/null 2>&1
        
        # 限制lucky配置备份数量
        ls -tp "$LUCKY_DIR"/lucky-backup-*.7z 2>/dev/null | tail -n +$(($MAX_LUCKY_FILES + 1)) | xargs -r rm -f
    fi
fi
```
最后我设置了每天0点和12点备份

```shell
# 确保脚本有执行权限
chmod +x /mnt/sda1/auto-backup.sh
# 添加定时任务
crontab -e
```
```shell
# 每天0点和12点执行备份
0 0,12 * * * /usr/local/bin/auto-backup.sh >/dev/null 2>&1
```
