利用ImmortalWrt自带的 uhttpd 来托管网页和执行脚本

``` shell
# 1. 创建网页根目录
mkdir -p /mnt/pve_web
# 2. 创建CGI脚本目录（将用于存放可执行脚本链接）
mkdir -p /mnt/pve_web/cgi-bin

# 检查uhttpd是否在运行（通常80端口已被LuCI占用）
netstat -tulpn | grep uhttpd
# 如果有多个，先停止所有
killall uhttpd
# 启动新的
uhttpd -p 18080 -h /mnt/pve_web -c /mnt/pve_web/cgi-bin &

# 验证
netstat -tlnp | grep 18080
```
然后创建HDMI文件与CGI脚本,我的目录结构如下

``` shell
 /mnt/pve/  
 ├── index.html  
 ├── favicon.ico  
 └── cgi-bin/  
     ├── ping_server.sh  
     ├── pve_shutdown.sh  
     └── pve_wake.sh  
```
