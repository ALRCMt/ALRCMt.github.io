路由器配置PassWall透明代理教程如下：
先安装Passwall相关包，如果你空间大，直接在网页安装全部包就行，但是我的空间比较小，所以采取了 [挂载外部储存介质](/jekyll/2025-06-20-n07.html) 来安装一些大文件的方法（缺点就是依赖自己管理）  
 
我选择将这些安装进外部介质：  
``` bash
opkg install xray-core -d usb          # 26MB
opkg install sing-box-tiny -d usb      # 28MB（选tiny版）
opkg install geoview -d usb            # 5MB（IP地理数据库）
opkg install chinadns-ng -d usb        # 0.5MB（分流DNS）
```

而这些安装进主空间（看你缺什么）  
```bash
opkg install coreutils coreutils-base64 coreutils-nohup dns2socks ipt2socks microsocks ip-full unzip libbpf1 libelf1 libltdl7 liblua5.3 libuci-lua
```

我选择不安装的包：  
`shadowsocks-rust-sslocal / shadowsocks-rust-ssserver`  `v2ray-plugin`  `haproxy`  `simple-obfs-client`  


然后建立软链接   

```bash
# 假设你的U盘挂载在 /mnt/usb
ln -s /mnt/usb/opkg_packages/usr/bin/xray /usr/bin/xray
ln -s /mnt/usb/opkg_packages/usr/bin/sing-box /usr/bin/sing-box
ln -s /mnt/usb/opkg_packages/usr/bin/chinadns-ng /usr/bin/chinadns-ng
```

再装 PassWall 本体（不拉取多余依赖）   
```bash
opkg install luci-app-passwall --nodeps
```

然后在 LuCI 界面配置  
浏览器刷新页面，导航到 服务 → PassWall  

在“节点订阅”里导入订阅，然后点击“手动订阅”，或者在“节点列表”里手动添加  
然后节点列表里就有可用节点了
