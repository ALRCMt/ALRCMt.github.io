可以把外部存储（比如U盘）挂载在ImmortalWRT做普通目录 和 外部 Overlay  
(因为原生的磁盘空间实在是太少了，几个软件包就满了)   

首先建议U盘系统刷ext4，其格式支持得最好，而且最好在Linux环境下操作  
使用 `fdisk` 和 `mkfs.ext4` 操作，没有相关包记得下载  

```bash
# 1. 查看 U 盘设备名
lsblk

# 2. 假设是 /dev/sda，开始分区
fdisk /dev/sda

# 删除所有原来的错误分区
# 依次输入：d, 1, d, 2, ... 直到全删光

# 我这里创建第一个分区（4G，用于 overlay）
# 输入：n, p, 1 回车, 回车（默认从2048开始）, +4G

# 创建第二个分区（16G，用于普通存储）
# 输入：n, p, 2 回车, 回车, +16G

# 如果显示如下，y删去这个旧签名
# Partition #1 contains a ext4 signature.
# Do you want to remove the signature? [Y]es/[N]o: 

# 保存分区表
# 输入：w
```
如果提示 w 写入成功后，在 ImmortalWRT 里格式化

```bash
# 格式化第一个分区为 ext4（overlay 需要）
mkfs.ext4 /dev/sda1

# 格式化第二个分区为 ext4（普通存储用）
mkfs.ext4 /dev/sda2
```

然后查看WEB的 **系统** > **挂载点** ，点击底部的 添加 按钮。

勾选“启用”以启用该挂载点  

**UUID**：在下拉菜单中选择你的U盘。建议使用UUID来识别设备，因为它是唯一的，即使U盘盘符发生变化也不会影响挂载  
**挂载点**：如果是普通存储用，在“自定义”输入框中，输入挂载路径 如 /mnt/sda1  
如果是作为外部挂载Overlay，选择 “作为外部Overlay挂载”

**文件系统**：在下拉菜单中选择你的U盘格式，如果不确定，可以留空让系统自动识别  

其他选项保持默认即可，然后点击 **保存**

应用配置：回到“挂载点”页面，点击右下角的 **保存并应用** 按钮，系统会自动尝试挂载   
如果成功，你可以在“已挂载的文件系统”列表中看到
> 如果是挂载Overlay，需要重启路由器生效
