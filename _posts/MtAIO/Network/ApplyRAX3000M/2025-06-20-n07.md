可以把外部存储（比如U盘）挂载在ImmortalWRT    
(因为原生的磁盘空间实在是太少了，几个软件包就满了)   

首先建议U盘系统刷ext4，其格式支持得最好，而且最好在Linux环境下操作  
使用 `fdisk` 和 `mkfs.ext4` 操作，没有相关包记得下载  

```bash
# 1. 查看 U 盘设备名
lsblk

# 2. 假设是 /dev/sda，开始分区
fdisk /dev/sda

# 删除所有原来的错误分区
# 依次输入：d, 1, d, 2, ... 直到全删光

# 我这里创建第一个分区（4G，用于 overlay <不建议这么做>）
# 输入：n, p, 1 回车, 回车（默认从2048开始）, +4G

# 创建第二个分区（16G，用于普通存储）
# 输入：n, p, 2 回车, 回车, +16G

# 如果显示如下，y删去这个旧签名
# Partition #1 contains a ext4 signature.
# Do you want to remove the signature? [Y]es/[N]o: 

# 保存分区表
# 输入：w
```
如果提示 w 写入成功后，在 ImmortalWRT 里格式化

```bash
# 格式化第一个分区为 ext4（overlay 需要）
mkfs.ext4 /dev/sda1

# 格式化第二个分区为 ext4（普通存储用）
mkfs.ext4 /dev/sda2
```

然后查看WEB的 **系统** > **挂载点** ，点击底部的 添加 按钮。

勾选“启用”以启用该挂载点  

**UUID**：在下拉菜单中选择你的U盘。建议使用UUID来识别设备，因为它是唯一的，即使U盘盘符发生变化也不会影响挂载  
**挂载点**：如果是普通存储用，在“自定义”输入框中，输入挂载路径 如 /mnt/sda1  
如果是作为外部挂载Overlay，选择 “作为外部Overlay挂载”   
**（如果你对自己介质的4K随机读取速度没有信心，那么千万不要这么做）**

**文件系统**：在下拉菜单中选择你的U盘格式，如果不确定，可以留空让系统自动识别  

其他选项保持默认即可，然后点击 **保存**

应用配置：回到“挂载点”页面，点击右下角的 **保存并应用** 按钮，系统会自动尝试挂载   
如果成功，你可以在“已挂载的文件系统”列表中看到
> 如果是挂载Overlay，需要重启路由器生效  

如果不是挂载Overlay，但是还想能安装更多软件包，操作如下：
```bash
# 在U盘上创建软件包目录
mkdir -p /mnt/sda1/opkg_packages

# 创建多个子目录
cd /mnt/sda1/opkg_packages
mkdir usr etc lib bin sbin www root
```
确认目录创建正确后，再修改配置文件 `/etc/opkg.conf`
在文件末尾添加一行：  

```bash
dest usb /mnt/sda1/opkg_packages
```

然后就可以安装较大的软件包到U盘  
```bash
# 安装到U盘（需要用 -d usb 参数）
opkg update
opkg install 7z -d usb

# 查看7z安装位置验证是否成功
find /mnt/sda1 -name "7z*"
```

为了让安装在U盘的应用全局可用，添加U盘路径到环境变量

```bash
# 添加到 profile
echo 'export PATH=$PATH:/mnt/sda1/opkg_packages/usr/bin:/mnt/sda1/opkg_packages/bin' >> /etc/profile

# 生效
source /etc/profile
```

注意，这个方法一定一定要处理好依赖问题，注意重要的依赖放在系统路径里   
比如我的aria2放在系统路径，ariang就可以放在挂载目录
