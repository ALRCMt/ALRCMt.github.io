当由于一些原因不得不重刷ImmortalWrt时，我们希望可以快速恢复配置  
所以编辑了这么一个备份脚本，自动备份WRT配置、已安装包名单及Lucky配置  

我将一个U盘插在RAX3000M的USB口上，并挂载在/mnt/sda1，将备份文件储存在其中  
TIPS：Lucky的备份格式是zip，请先安装软件包`7z`以获取zip支持

```shell
# 编辑脚本，目录随便
nano /mnt/sda1/auto-backup.sh
```
```shell
#!/bin/sh

# 简单备份脚本
BACKUP_DIR="/mnt/sda1/TarBack"
PKG_DIR="/mnt/sda1/PackageBack"
LUCKY_DIR="/mnt/sda1/LuckyBack"
# 备份文件数量上限，去旧留新
MAX_BACKUP_FILES=10
MAX_PKG_FILES=5
MAX_LUCKY_FILES=10

# 创建备份目录
mkdir -p "$BACKUP_DIR" 2>/dev/null
mkdir -p "$PKG_DIR" 2>/dev/null
mkdir -p "$LUCKY_DIR" 2>/dev/null

# 1. 生成系统备份文件
sysupgrade -b "/tmp/backup-$$.tar.gz" 2>/dev/null

# 移动到备份目录并重命名
if [ -f "/tmp/backup-$$.tar.gz" ]; then
    BACKUP_NAME="backup-ImmortalWrt-$(date +%Y%m%d-%H%M%S).tar.gz"
    mv "/tmp/backup-$$.tar.gz" "$BACKUP_DIR/$BACKUP_NAME" 2>/dev/null
    
    # 限制备份文件数量
    ls -tp "$BACKUP_DIR"/backup-*.tar.gz 2>/dev/null | tail -n +$(($MAX_BACKUP_FILES + 1)) | xargs -r rm -f
fi

# 2. 备份已安装软件包列表到另一个文件夹
PKG_FILE="installed-packages-$(date +%Y%m%d-%H%M%S).txt"
opkg list-installed > "$PKG_DIR/$PKG_FILE" 2>/dev/null

# 限制软件包列表文件数量
ls -tp "$PKG_DIR"/installed-packages-*.txt 2>/dev/null | tail -n +$(($MAX_PKG_FILES + 1)) | xargs -r rm -f

# 3. 备份lucky配置（.lkcf文件）
if [ -d "/etc/config/lucky.daji" ]; then
    LUCKY_FILE="lucky-backup-$(date +%Y%m%d-%H%M%S).7z"
    
    # 查找.lkcf文件
    LKCF_FILES=$(find "/etc/config/lucky.daji" -name "*.lkcf" -type f 2>/dev/null)
    
    # 如果有.lkcf文件，则用7z打包
    if [ -n "$LKCF_FILES" ]; then
        # 使用7z创建压缩包
        7z a -t7z "$LUCKY_DIR/$LUCKY_FILE" $LKCF_FILES >/dev/null 2>&1
        
        # 限制lucky配置备份数量
        ls -tp "$LUCKY_DIR"/lucky-backup-*.7z 2>/dev/null | tail -n +$(($MAX_LUCKY_FILES + 1)) | xargs -r rm -f
    fi
fi
```
最后我设置了每天0点和12点备份

```shell
# 确保脚本有执行权限
chmod +x /mnt/sda1/auto-backup.sh
# 添加定时任务
crontab -e
```

```shell
# 每天0点和12点执行备份
0 0,12 * * * /usr/local/bin/auto-backup.sh >/dev/null 2>&1
```
