请注意nand版与emmc版的固件不同，rax3000M与me之类也是不同的  
有官方固件也有各大佬自编译的，请注意旧固件格式.bin与官方新版.itb不一致，Uboot也必须一一对应  
不然喜提黑砖，就准备TTL救砖吧  

如果不想折腾，推荐刷ImmortalWRT官方固件，或者直接买刷好了的   
刷入及部分配置教程：

##### 一、 硬件确认  
版本识别：查看背面标签。仅显示“CH”为NAND版；显示“CH EC”为eMMC版  
只展示NAND版教程  
  
##### 二、 开启 SSH  
方法：修改配置文件导入  
登录原厂Web后台（192.168.10.1）
导出配置文件`cfg_export_config_file.conf`
解密与修改：
使用 OpenSSL 解密：
```shell
openssl aes-256-cbc -d -pbkdf2 -k '$CmDc#RaX30O0M@!$' -in [文件名] | tar -zxvf - 
```

> 若解密报错，说明未加密，直接用 `tar -xvzf` 解压 

修改 `etc/config/dropbear`：设置 enable 为 1  
修改 `etc/shadow`：将 root 密码字段置空（删除前两个冒号间的内容）  
重新打包导入：  
加密打包  
```shell
tar -zcvf - etc | openssl aes-256-cbc -pbkdf2 -k '$CmDc#RaX30O0M@!$' -out new_config.conf 
```

> 未加密的版本：`tar -zcvf cfg_export_config_file_new.conf etc`

在Web界面导入 `new_config.conf`，路由器自动重启  
登录：使用 SSH 工具连接 192.168.10.1，用户 root，无密码 

##### 三、 备份原厂固件（关键步骤）
查看分区：`cat /proc/mtd` 

备份全分区：使用 dd 命令备份 `mtd0` 至 `mtd11`  
注意：NAND 内存较小，备份一个分区后需立即通过 WinSCP 下载至电脑并从路由器删除，防止内存溢出重启 

##### 四、 刷入 U-Boot
目前ImmortalWrt24.10.0之后固件格式为.itb，与之前.bin的教程不太一样，这里只放新版的教程  
我使用1715173329大大的改版U-Boot，自带DHCP与WEB界面  

[恩山大佬原帖：MT798x 全家桶不死 U-Boot 支持自动下发 DHCP](https://www.right.com.cn/FORUM/thread-8328967-1-1.html)  
[U-boot下载地址：https://drive.wrt.moe/uboot/mediatek](https://drive.wrt.moe/uboot/mediatek)  

上传 `mt7981-cmcc_rax3000m-nand-fip-expand.bin` 至 `/tmp`  
写入命令：`mtd write /tmp/mt7981-cmcc_rax3000m-nand-fip-expand.bin FIP`  
注意：命令中 FIP 必须大写  
进入方式：断电，按住 Reset 键上电，灯变绿后松开  
直接就可以登陆 192.168.1.1，进入U-Boot界面  

##### 五、 刷入 ImmortalWrt  
通过U-Boot刷入下载好的KERNEL固件（immortalwrt-24.10.0-mediatek-filogic-cmcc_rax3000m-initramfs-recovery.itb）  
待刷后重启进入WEB管理页 `immortalwrt.lan`   
再升级刷 SYSUPGRADE固件（immortalwrt-24.10.0-mediatek-filogic-cmcc_rax3000m-squashfs-sysupgrade.itb ）  

有新旧固件格式更新参考：[RAX3000M 更换U-Boot](https://www.right.com.cn/FORUM/thread-8417494-1-1.html)
注意大小写问题，有的机型要大写有的又要小写

官方固件：[ImmortalWRT](https://firmware-selector.immortalwrt.org/)  
恩山237大佬的固件：[7981高功率闭源驱动插件openwrt](https://www.right.com.cn/FORUM/thread-8263340-1-1.html)  
我刷的固件：[RAX3000M-237大佬仓库编译自用闭源固件24.10内核版本](https://www.right.com.cn/forum/thread-8433653-1-1.html)   
同上固件的GitHub库：[https://github.com/jiehuihui/immortalwrt24.10-6.6-cmcc_rax3000m-237](https://github.com/jiehuihui/immortalwrt24.10-6.6-cmcc_rax3000m-237)  
如果更懒，直接小黄鱼上买的已经刷好的的版本，价格差不多  

刷好了之后连接到路由器，默认ip：192.168.1.1  
可以SSH修改默认ip

``` shell
vim /etc/config/network # 打开配置文件
```
找到config interface 'lan'部分，将option ipaddr的值修改为你想要的IP地址  
保存并退出，运行`/etc/init.d/network restart`以应用更改
