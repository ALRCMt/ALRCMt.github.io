zram 是 Linux 内核中的一个模块，它在内存里创建压缩块设备（如 /dev/zram0），可以用来做 swap 或临时存储，从而节省内存并提升 I/O 性能  
而我们RAX3000M的内存显然十分吃紧，总共就 496 MB 的内存，所以使用zram来缓解内存不足的问题（虽然不治本）  
配置方法如下  

```bash
# 安装 zram-swap（如果还没装）
opkg update
opkg install zram-swap

# 1. 关闭所有 swap
swapoff -a 2>/dev/null
```

编辑配置文件 `/etc/config/zram-swap`  
默认内容大概是这样，修改 size_mb 为 512（使你自己实际内存数而定）：

``` bash
config zram
        option enabled '1'
        option size_mb '512'          # ← 改成 512
        option compression_algorithm 'lz4'
```
启动 zram  
```bash
# 启用开机自启
/etc/init.d/zram enable

# 立即启动
/etc/init.d/zram start
```
`free -m`验证，预期输出如下：  
```bash
              total        used        free      shared  buff/cache   available
Mem:         496372      177440      241948         456       76984      303040
Swap:        524284           0      524284
```
