有时想外网SSH到路由器，但是又苦于没有公网IP，可以使用Cloudflare Tunnel 服务来做到这一点（就是有时网络不太理想）
前提：你需要拥有一个已添加到 Cloudflare 账户进行管理的域名，再开启 Zero Trust   


在 ImmortalWrt 路由器上安装相关软件，如果你空间足够，直接安装就行  
```bash
opkg update
opkg install cloudflared luci-app-cloudflared luci-i18n-cloudflared-zh-cn 
```
而我空间不太够，安装在外部挂载了，详见：[挂载外部储存介质](/jekyll/2025-06-20-n07.html)

```bash
opkg install cloudflared -d usb # 安装在挂载点
opkg install luci-i18n-cloudflared-zh-cn --force-depends # 忽视cloudflared不在主分区的问题
```

1.登录 Cloudflare 账户：
```bash
cloudflared tunnel login
```
执行后会输出一个链接。在浏览器中打开该链接，登录你的 Cloudflare 账户并授权。成功后，会在 `/root/.cloudflared/` 目录下生成 cert.pem 证书文件

2.创建隧道：
```bash
cloudflared tunnel create <你的隧道名称>
```
命令执行后会在 `/root/.cloudflared/` 目录下生成一个 <隧道UUID>.json 的凭证文件

3.分配域名：
```bash
cloudflared tunnel route dns <隧道名称或UUID> <你想要使用的子域名>
```
这条命令会自动在 Cloudflare DNS 中添加一条 CNAME 记录

4.创建并编辑配置文件 `/etc/cloudflared/config.yml`
```bash
tunnel: <你的隧道名称或UUID>
credentials-file: /root/.cloudflared/<隧道UUID>.json
#protocol: http2 如果QUIC协议遇到障碍请启用仅使用HTTP2
#edge-ip-version: "6" 可填 4 或 6 ，选择仅使用ipv4或ipv6

ingress:
  - hostname: <你的子域名>
    service: ssh://localhost:22   # 转发到路由器的 SSH 服务
  - service: http_status:404      # 默认规则，必须保留
```

5.验证配置：
```bash
cloudflared tunnel ingress validate
```
如果配置无误，会输出 OK

6.前台运行测试：

```bash
cloudflared tunnel run <隧道名称或UUID>
```
如果看到 `INF Registered tunnel connection` 等日志，说明隧道运行成功。按 Ctrl+C 停止测试

设置开机自启（路由器端）  
隧道现在在前台运行，按 Ctrl+C 会停止。需要让它后台运行并开机自启：  

```bash
# 创建 init.d 脚本
cat > /etc/init.d/cloudflared << 'EOF'
#!/bin/sh /etc/rc.common

START=99
STOP=10
USE_PROCD=1

start_service() {
    # 开机等待 40 秒，确保代理链路已完全启动
    sleep 40

    procd_open_instance
    procd_set_param command /usr/bin/cloudflared tunnel 

    # cloudflared 掉线时自动拉起
    procd_set_param respawn 300 5 5

    # 输出日志到系统日志
    procd_set_param stdout 1
    procd_set_param stderr 1

    procd_close_instance
}

stop_service() {
    # 正确停止 procd 管理的实例
    procd_kill cloudflared
}
EOF
```
```bash
chmod +x /etc/init.d/cloudflared

/etc/init.d/cloudflared enable
/etc/init.d/cloudflared start
/etc/init.d/cloudflared status # 检查状态
```

然后是远程连接的方式  

#### 一.浏览器终端（客户端零安装）  
这是最简单的连接方式，你只需要一个浏览器，不需要在电脑上装任何东西  

配置 Cloudflare Access   
登录 Cloudflare Zero Trust 面板  

进入 Networks → Tunnels & Mesh，找到你刚创建的 隧道   
点击隧道名称进入详情，切换到 Published application routes 标签   
点击 Add a published application route：    
Subdomain：ssh（或你想要的任意子域名）   
Domain：（你的主域名）  
Type：选择 SSH  
URL：填写 localhost:22（因为 cloudflared 运行在路由器上，SSH 服务也在路由器上）

> 可能会弹出 “本地配置的隧道，无法从 Zero Trust 控制面板管理，但是，您可以选择迁移其入站规则以从控制面板管理” ，选择迁移就好  

（可选但推荐）添加 Access 策略来保护 SSH 入口：  
在 Zero Trust 面板进入 Access controls → Applications，点击 Add an Application → 选择 Self-hosted，填写你的子域名  
在 Policies 中添加一条规则，例如：允许你的邮箱登录（使用 Emails 作为规则）    

完成后，访问浏览器终端时会要求验证邮箱

#### 二.使用原生 SSH 客户端（Windows）  


下载 Windows 版 cloudflared：

从 [https://github.com/cloudflare/cloudflared/releases](https://github.com/cloudflare/cloudflared/releases) 下载 cloudflared-windows-amd64.exe

重命名为 cloudflared.exe，放到 `C:\Windows\System32\` ，
连接测试 
```shell
ssh -o ProxyCommand="cloudflared access ssh --hostname <你的域名>" root@<你的域名>
```

改良网络与使用，编辑 SSH 配置文件 `C:\Users\您的用户名\.ssh\config` ，添加如下内容，保存后，就可以直接ssh   

```shell
Host <你的域名>
    HostName <你的域名>
    User root
    ProxyCommand <cloudflared安装路径> access ssh --hostname %h
    Compression yes
    Ciphers chacha20-poly1305@openssh.com
    IdentityFile <SSHKey的路径>
```

提示：
