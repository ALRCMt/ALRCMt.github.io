安装在ImmortalWRT上的Aria2突然无法启动了
运行 `/ect/usr/aria2 start` 后，服务状态始终为 not running

日志显示错误：

```bash
Exception: [Platform.cc:125] errorCode=1 OSSL_PROVIDER_load 'legacy' failed.
```
表明 OpenSSL 无法加载 legacy 提供程序

根本原因:  
OpenSSL 3.x 将旧版算法（如 MD5、RC4 等）移至独立的 `legacy` 模块，需要环境变量 `OPENSSL_MODULES` 指向该模块所在的目录（`/usr/lib/ossl-modules`）

aria2 的启动脚本使用了 `procd` 的 `jail` 沙盒机制，隔离了环境变量，导致即使设置了 `procd_set_param env` 或命令前加 `env`，环境变量也无法传递到 `jailed` 进程中

因此最可靠的办法是禁用 `jail`，让 `aria2` 在普通进程中运行  

编辑脚本 `/etc/init.d/aria2`  
查找并注释掉 `jail` 相关行：

```bash
# procd_add_jail "$NAME.$section" log
# procd_add_jail_mount "$ca_certificate" "$certificate" "$rpc_certificate" "$rpc_private_key"
# procd_add_jail_mount_rw "$dir" "$config_dir" "$log"
```

验证状态：
```bash
/etc/usr/aria2 start
/etc/usr/aria2 status
logread | grep -i aria2 | tail -20
```
应不再出现 `OSSL_PROVIDER_load 'legacy' failed` 错误，且服务状态变为 `running`
