在我使用ImmortalWRT时会遇到各类中文乱码的情况，各解决方法如下

设置系统 Locale，主要解决 "文件内容显示乱码" 和 "终端输出乱码" 的问题  
```bash
echo 'export LANG=en_US.UTF-8' >> /etc/profile
echo 'export LC_CTYPE=en_US.UTF-8' >> /etc/profile

source /etc/profile # 让当前会话生效
```
验证是否设置成功：`echo $LANG`  
应该输出 `en_US.UTF-8`

在使用`nano`时发现中文无法正常显示，反复配置也不行，最后发现应该安装完整版`nano-full`才支持中文符号  

而有时已经进行了如上配置，在跨平台文件操作时发现乱码问题，多半是编码方式不一样导致的  
比如windows文件使用GBK编码，虽然可以打开`使用“Unicode UTF-8 提供全球语言支持”的 Beta 版功能` ，但是会影响一些依赖 GBK 的老程序，如果直接把windows上创建的文件移动到Linux，多半会乱码  
如果有已乱码的文件，使用如下命令转换（需要`iconv`包支持）：

```bash
# 批量转换文件名从 GBK 到 UTF-8
for f in *; do
    # 跳过目录
    [ -d "$f" ] && continue
    
    # 尝试将文件名从 GBK 转为 UTF-8
    newname=$(echo "$f" | iconv -f GBK -t UTF-8 2>/dev/null)
    
    # 如果转换成功且新名字不同，则重命名
    if [ $? -eq 0 ] && [ "$f" != "$newname" ] && [ -n "$newname" ]; then
        mv "$f" "$newname"
        echo "重命名: $f → $newname"
    fi
done
```

如果在Windows使用`scp` `sftp`等时，要设置使用utf-8编码，不然windows这边也会乱码
