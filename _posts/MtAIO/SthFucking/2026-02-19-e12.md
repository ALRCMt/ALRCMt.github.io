有时发现路由器莫名其妙就没有了公网IPV6，一查才发现小气ISP只给了/64 前缀   
（但有的时候又给/60、/56）  
即使打开了 前缀委派 (PD)，也无法再切分给 LAN  

解决方案有二：  

**一. 复用 /64 前缀**  
在 ImmortalWrt 的 LAN 接口里手动指定 WAN6 的 /64 前缀，让 LAN 设备直接用这个前缀  
缺点：LAN 和 WAN 在同一个 /64，拓扑上不够优雅，但能用

**二. 光猫桥接模式**  
如果光猫支持桥接，可以让 ImmortalWrt 直接拨号获取 IPv6，这样路由器能完整接管 IPv6 分配  

我懒得折腾，直接选了方案一  
编辑`/etc/config/network`，设置如下三处   
```bash
config interface 'wan6'
    option device 'eth1'
    option proto 'dhcpv6'
    option reqaddress 'force'
    option reqprefix 'auto'   # ISP 给 /56 或 /60 ImmortalWrt 会自动拿到更大的前缀
    option norelease '1'

config interface 'lan'
    option device 'br-lan'
    option proto 'static'
    option ipaddr '192.168.6.1'
    option netmask '255.255.255.0'
    option ip6assign '64'     # LAN 始终分配一个 /64
    option ip6ifaceid '::1'   # LAN 网关地址后缀

```

重启网络  
```bash
/etc/init.d/network restart
```
