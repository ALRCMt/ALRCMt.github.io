在将硬盘直通给TrueNAS后，PVE仍会尝试挂载ZFS，同时访问**可能**会导致**数据损坏**  
所以应该确保 PVE 宿主机不主动挂载或导入该 ZFS 池，而是由 TrueNAS 虚拟机独占访问  

立即导出 ZFS 池(如果已导入)
``` shell
zpool export MtData
```
因为我的PVE系统没有使用ZFS作为根文件系统，而是使用**LVM+ext4**  
所以我直接简单粗暴，完全移除ZFS工具  
``` shell
sudo apt purge zfsutils-linux zfs-zed -y
```
