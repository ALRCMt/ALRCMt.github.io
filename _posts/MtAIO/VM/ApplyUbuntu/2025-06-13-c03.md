**I.命令行加速**

编辑`/etc/docker/daemon.json`，加入以下内容

```shell
{
  "registry-mirrors": [
    "https://docker.1ms.run",
    "https://docker.m.daocloud.io",
    "https://registry.cn-hangzhou.aliyuncs.com"
  ],
}
```

保存并退出

**II.面板加速**

在 DPanel 内选择**仓库管理**，编辑 Docker Hub 仓库  
添加加速地址，下面有推荐加速地址
