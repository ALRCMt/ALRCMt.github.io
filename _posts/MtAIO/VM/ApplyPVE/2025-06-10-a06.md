有的时候，你可能需要跨系统进行文件传输  
比如我需要将某个硬盘的数据导入到TrueNAS上，但是数据太大不方便网络传输
所以可以将硬盘插到物理接口上，然后挂载这个硬盘

``` shell
# 创建挂载点目录
mkdir -p /mnt/external_drive

# 查看移动硬盘的分区信息
fdisk -l | grep '^Disk /dev\|^/dev/'

# 挂载移动硬盘（假设它是单个分区 /dev/sdc1）
mount -t auto /dev/sdc1 /mnt/external_drive  # 自动检测

mount -t ntfs /dev/sdc1 /mnt/external_drive  # NTFS 文件系统
mount -t vfat /dev/sdc1 /mnt/external_drive  # FAT32 文件系统
mount -t exfat /dev/sdc1 /mnt/external_drive # exFAT 文件系统

# 如果遇到 NTFS 文件系统的问题，可能需要安装 NTFS 支持
apt update
apt install ntfs-3g

# 确认挂载成功
df -h /mnt/external_drive
ls /mnt/external_drive
```
然后通过ssh传输到TrueNAS池里，如果反过来就把命令里两个文件夹对换
``` shell
# 使用 rsync（支持断点续传和进度显示）
rsync -av --progress /mnt/external_drive/ root@<TrueNAS_IP>:/path/to/destination/

#  如果未安装
apt update
apt install rsync

```
不知道为什么有可能会出现权限混乱的问题。我直接选择在TrueNAS的控制台把文件夹权限改了
``` shell
su root 
chmod -R 777 /mnt/池/文件夹
```
