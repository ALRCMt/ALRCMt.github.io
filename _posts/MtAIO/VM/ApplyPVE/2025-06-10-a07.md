这里先直接运行以下命令，确保更新到8.4.8版本：

```bash
apt update #更新源

apt dist-upgrade #更新软件、系统

pveversion #检查系统版本
```
然后执行命令`pve8to9 --full`，检查是否能正常升入到9.0版本
看到类似输出：
``` bash
root@pve:~#  pve8to9 --full
= CHECKING VERSION INFORMATION FOR PVE PACKAGES =

Checking for package updates..
PASS: all packages up-to-date

Checking proxmox-ve package version..
PASS: proxmox-ve package has version >= 8.4-0

#.......中间内容省略

= SUMMARY =

TOTAL:    42
PASSED:   30
SKIPPED:  6
WARNINGS: 3
FAILURES: 1
```

有WARN不要慌，一般都不是问题，只要不出现“FAIL”失败就行，照着WARN提示确认下没问题就可以正常升级
而FAIL问题必须解决才能正常升级

我这里存在的问题： 

**1.systemd-boot 冲突**
```bash
FAIL: systemd-boot meta-package installed. This will cause problems on upgrades of other boot-related packages. 
```
原因：系统安装了 systemd-boot 包，这通常用于 UEFI 启动，但 PVE 9 升级时会与它冲突  
解决方案是直接移除`apt remove systemd-boot` 

**2.旧的 sysctl.conf 需要迁移**
```bash
WARN: Deprecated config '/etc/sysctl.conf' contains settings - move them to a dedicated file in '/etc/sysctl.d/'.
```
原因：Debian 13 开始不建议使用 /etc/sysctl.conf，需要将配置拆分成单独的文件  
解决方案：  
创建一个新的配置文件 `/etc/sysctl.d/99-custom.conf`，然后把 `/etc/sysctl.conf` 里所有非注释的行复制过去，然后清空原文件

```bash
mkdir -p /etc/sysctl.d
cp /etc/sysctl.conf /etc/sysctl.d/99-custom.conf
echo "" > /etc/sysctl.conf
```

**3. WARN: 缺少 AMD CPU 微码**
```bash
WARN: The matching CPU microcode package 'amd64-microcode' could not be found!
```
原因：CPU没有安装对应的微码更新包，这可能会影响系统稳定性

解决方案：
先确认 non-free-firmware 源已启用：`grep -r "non-free" /etc/apt/sources.list`  
如果没有，需在 /etc/apt/sources.list 中添加 non-free-firmware：
```bash
deb https://mirrors.ustc.edu.cn/debian trixie main contrib non-free-firmware
```

然后安装微码：
```bash
apt update
apt install amd64-microcode #amd cpu安装这个 
apt install intel-microcode #intel cpu安装这个
```

最后，再次`pve8to9 --full`确认下，没FAIL就行，如果有，一定要在升级前手动修复  
确认上面的检查没问题后，就可以修改软件源准备更新  
修改软件源按照里[设置 PVE 的 APT 源](/jekyll/2025-06-10-a01.html)的PVE 9.x的教程来就行

再次检查无误后，就可以输入以下命令直接升级：
```bash
apt dist-upgrade
```
一开始要升级会有个文本要阅读，我没仔细看是啥，直接输入“q”退出就行，之后会提示部分组件升级期间要自动重启，选择“yes”，然后还会有部分更新询问怎么处理配置文件，输入“y”选择安装新配置，如果担心出现问题，输入“n”保留原来的也行，如果此前修改了系统配置的，建议都选择n保留

最后安装完成，可以再次输入`pve8to9`查看是否有问题，无误就直接重启系统，重启后可以使用`pveversion`命令查看当前系统版本
