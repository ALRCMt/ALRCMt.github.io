编辑`/etc/network/interfaces`  
修改IP地址：找到包含address的行，修改为新的IP地址  
如果需要更改网关，也要修改gateway这一行，完成后保存并退出   
重启网络 `systemctl restart networking`  
如果你有闲心，也可以把`/etc/hosts`和`/etc/issue`也改了，使开机显示IP与实际一致  
意义不大~~我有强迫症~~

如果你有使用IPV6的需要，那么需要配置IPV6  
我选择的是直接通过网桥接收路由器广播的RA（路由通告），使用SLAAC自动配置生成地址  
你需要首先修改路由器相关内容：[**SLAAC自动分配IPV6**](/jekyll/2025-06-16-n03.html)  
然后修改`/etc/network/interfaces`  
``` shell
auto vmbr0
iface vmbr0 inet static
        address 192.168.6.217/24
        gateway 192.168.6.1
        bridge-ports enp34s0
        bridge-stp off
        bridge-fd 0
iface vmbr0 inet6 auto #添加这一项
```
`systemctl restart networking` 重启网络  

再修改 `/etc/sysctl.conf`,末尾添加以下两行
``` shell
net.ipv4.ip_forward=1
net.ipv6.conf.vmbr0.accept_ra = 2
```
`sysctl -p` 应用并重启

请注意！现在可能虚拟机会断网，你需要reboot完全重启PVE，之后就会正常

`ip -6 addr show` 查看是否获得了公网IPV6地址，再外网ping一下试试
