我在这里谈论的，不是Immich自带的机器学习，而是如果你本地没有计算卡，只有其它AI模型的API的检索方案  
方法是利用Immich里每张图片的“描述”，使用AI生成描述与关键词来检索

首先创建Immich的用户API，需要的权限是 `asset.read` `asset.update` `asset.download`，复制KEY

然后我们借助Python脚本来接入AI，安装相应工具  
```bash
# 1. 更新系统
apt update

# 2. 安装 Python3 和 pip
apt install python3 python3-pip python3-full -y

# 3. 安装 Python 包
pip3 install requests openai --break-system-packages

# 4. 安装 ImageMagick 主要用来处理 HEIC 图片和压缩大图
apt install imagemagick libheif-examples -y
```

然后在你喜欢的位置创建py脚本，脚本的作用是扫描全库的图片，如果没有描述则识图生成描述与关键词，如果有描述，就根据描述与图片生成关键词，方便检索  
另外还有一个检测是否有孤立xmp文件的功能（防止无用的xmp文件）  
脚本内容在此：[**immich_ai_tagger.py**](https://github.com/ALRCMt/MtAIO-Build/blob/main/immich_ai_tagger.py)  记得改开头的各个API（你用的AI必须要有识图功能）以及文件夹名称

可以运行测试一下，如果没问题，你就可以设置定时或开机什么时候执行
