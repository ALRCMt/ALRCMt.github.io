初配置与[PVE电源控制面板](/jekyll/2025-06-19-n06.html)一样，这里不再赘述  
新增了系统切换与系统识别的部分 `switch.sh`，显然你可以把WIN换成任何你想切换的系统  
这里只展示差异的内容，目录结构如下：

```
 /mnt/pve_web/  
      ├── index.html  
      ├── favicon.ico  
      └── cgi-bin/  
         ├── ping_server.sh  
         ├── multi_shutdown.sh  
         ├── pve_wake.sh  
         └── switch.sh
```
WEB文件：[https://github.com/ALRCMt/MtAIO-Build/tree/main/pve_web_plus](https://github.com/ALRCMt/MtAIO-Build/tree/main/pve_web_plus)

要注意的点：  
脚本在ImmortalWRT使用了`tcping` `shpass` `etherwake`三个包，PVE使用了 `efibootmgr` ，如果没有请安装  
同时要确定 Windows 启动项编号  
``` shell
# 查看 Windows 启动项编号
efibootmgr | grep -i windows
# 假设输出：Boot0001* Windows Boot Manager
# 则switch.sh脚本中为 efibootmgr --bootnext 0001 && reboot
```
切换的系统Windows需要安装OpenSSH，教程：[Windows安装OpenSSH](/jekyll/2026-04-06-WINOpenSSH.html)
