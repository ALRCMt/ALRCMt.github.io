我在这里谈论的，不是 Immich 自带的机器学习，而是用外部 AI 接口实现“语义检索”。
思路很简单：把媒体库里的图片和视频先统一生成描述、标签和关键词，再把这些文本写回 Immich 的描述字段，后续自然语言搜索就能直接命中内容，而不需要本地显卡或依赖 Immich 自带的 AI 能力。

对于视频，脚本会按时间轴均匀抽取若干关键帧，再将这些帧一起发给 AI 进行整体判断，避免只看某一帧造成偏差。对于图片，则直接识图生成描述和关键词。

实现原理大致是：

1. 通过 Immich API 拉取媒体详情；
2. 判断是否超大文件，避免下载和处理卡住；
3. 对图片直接送给 AI 识图；
4. 对视频按时间点抽帧并打包分析；
5. 如果媒体原本没有描述，就生成描述 + 关键词；
6. 如果已有描述，则根据当前内容补充关键词；
7. 最后写回 Immich 的 description 字段，供后续语义搜索、标签筛选和相册整理使用；
8. 识别失败时还会记录到过滤名单，避免重复消耗 API，并减少无效内容污染库。

这样做的好处是：不需要本地显卡，也能把整个媒体库变成“可搜索内容库”。如果你有相册管理需求，还可以在生成结果后按需导出到指定相册，进一步做内容聚类和整理。

然后我们借助Python脚本来接入AI，安装相应工具  
```bash
# 1. 更新系统
apt update

# 2. 安装 Python3 和 pip
apt install python3 python3-pip python3-full -y

# 3. 安装 Python 包
pip3 install requests openai --break-system-packages

# 4. 安装 ImageMagick 主要用来处理 HEIC 图片和压缩大图
apt install imagemagick libheif-examples -y

# 5. 安装 ffmpeg 主要用来处理视频抽帧
apt install -y ffmpeg
```

然后在你喜欢的位置创建 Python 脚本。

脚本内容在此：[**immich_ai_tagger.py**](https://github.com/ALRCMt/MtAIO-Build/blob/main/immich_ai_tagger.py) ，以及增强版的视频支持脚本：[**immich_ai_tagger_v2.py**](https://github.com/ALRCMt/MtAIO-Build/blob/main/immich_ai_tagger_v2.py)。

记得改开头的 API 配置（你用的 AI 必须要有识图功能），同时按自己的 Immich 地址、相册规则和文件夹环境调整。

可以先运行测试一下。如果效果正常，再设置定时任务、开机自启，或者放到后台定期更新。
