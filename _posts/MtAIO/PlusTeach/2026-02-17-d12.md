由于特殊原因，我为服务器实体机装了双系统，除开PVE还有一个Win10  
其于一独立硬盘上，有的时候需要进入WIN（不要问我为什么有这个需求），但是Grub默认不显示其它硬盘系统，同时切换也需要实体操作，十分麻烦   

所以我们需将Windows选项加入Grub，以便可以在开机时选择（默认PVE）  
首先挂载Windows的EFI分区并确认引导文件  
```shell
# 创建挂载点
mkdir -p /mnt/windows_efi

# 挂载sde1
mount /dev/sde1 /mnt/windows_efi

# 检查Microsoft引导文件是否存在
ls /mnt/windows_efi/EFI/Microsoft/Boot/
你应该能看到 bootmgfw.efi 这个文件，这是Windows的引导管理器。

# 安装os-prober（如果没有）
apt update
apt install os-prober

# 启用os-prober功能
echo "GRUB_DISABLE_OS_PROBER=false" >> /etc/default/grub

# 手动探测其他系统
os-prober
如果成功，输出应该类似：/dev/sde1@/EFI/Microsoft/Boot/bootmgfw.efi:Windows Boot Manager:Windows

# 更新GRUB配置
update-grub

# 清理并重启
umount /mnt/windows_efi
reboot
```

如果上述步骤没有成功  
可能是因为GRUB在生成配置时没有正确识别。你可以手动添加一个菜单项：  
先获取Windows EFI分区的UUID `blkid /dev/sdx1`  
输出类似：  
`/dev/sdx1: UUID="67E3-17ED" ...`

编辑`/etc/grub.d/40_custom`
在文件末尾添加以下内容：  

```shell
menuentry "Windows 10" {
    insmod part_gpt
    insmod fat
    insmod chain
    search --fs-uuid --no-floppy --set=root 67E3-17ED #替换为你的UUID
    chainloader /EFI/Microsoft/Boot/bootmgfw.efi
}
```

再更新Grub并重启，应该可以看见`Windows 10`选项  
```shell
update-grub
reboot
```

那么问题来了，我如何在不操作实体机的情况下切换系统呢？  
由于一些原因，PVE的`grub-reboot`不会自动清除，所以使用更直接的` efibootmgr`  

```shell
# 查看 Windows 启动项编号
efibootmgr | grep -i windows

# 假设输出：Boot0001* Windows Boot Manager
# 一次性切换到 Windows
efibootmgr --bootnext 0001 && reboot
```
这样重启后就进入了Windows，在win内重启又会回到PVE
