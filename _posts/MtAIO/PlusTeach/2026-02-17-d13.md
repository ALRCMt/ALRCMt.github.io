WEB文件：[https://github.com/ALRCMt/MtAIO-Build/tree/main/pve_web_plus](https://github.com/ALRCMt/MtAIO-Build/tree/main/pve_web_plus)

要注意的点：  
脚本使用了`tcping` `shpass` `etherwake` `efibootmgr` 四个包，如果没有请安装  
同时要确定 Windows 启动项编号  
``` shell
# 查看 Windows 启动项编号
efibootmgr | grep -i windows
# 假设输出：Boot0001* Windows Boot Manager
# 则switch.sh脚本中为 efibootmgr --bootnext 0001 && reboot
```
切换的系统Windows需要安装OpenSSH，教程：[Windows安装OpenSSH](/jekyll/2026-04-06-WINOpenSSH.html)
